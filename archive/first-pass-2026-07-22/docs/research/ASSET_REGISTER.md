# Asset register

The redesign reuses only first-party ROOSA media discovered on the current public site. Reference-template media and code are not copied.

| Local asset | Source | Intended use |
| --- | --- | --- |
| `public/media/brand/roosa-wordmark.png` | Current ROOSA site | Brand wordmark |
| `public/media/products/*` | Current ROOSA product catalogue | Product and fallback imagery |
| `public/media/impact/*` | Current ROOSA site | Existing partner marks; display remains subject to client approval |
| `public/media/journal/*` | Current ROOSA journal | Editorial placeholders for migrated stories |

All source URLs are encoded in `scripts/download-assets.mjs`. Product specifications and impact claims are intentionally not inferred from images.
