# ImpactSystem specification

## Overview

- Targets: `ImpactSteps.tsx`, `ImpactMetrics.tsx`, `ProjectCard.tsx` and impact routes.
- Interaction model: static + one-time viewport reveal.

## Structure

Purchase → contribution allocation → verified partner → named project → documented outcome.

## Exact implementation values

- Dark green report section: `#204f45`; paper text.
- Metrics: 3-column desktop, one column mobile; 1px translucent dividers.
- Paper line: 10px pink line with 28px repeating perforations.
- Project media: 4/3, documentary treatment; no hover zoom.

## Data rules

- Each metric includes reporting period and source.
- Missing values display bracketed placeholders, never invented figures.
- Sensitive imagery receives no decorative animation.
