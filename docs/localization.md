# Localization

- Supported route prefixes: `/en`, `/de`, `/fr`.
- Language and country remain separate concepts; the selector changes language only.
- English is the current source locale.
- Navigation and homepage proposition have initial translations; all legal, CMS and commerce content requires native review.
- Metadata alternates include `hreflang` entries and an `x-default` to `/en`.
- Currency, inventory, shipping and retailer routing will use Shopify Markets or an approved commerce-market adapter, not language alone.
