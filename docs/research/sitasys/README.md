Source: <https://sitasys-interactions.webflow.io/>

Local: <http://127.0.0.1:3000/sitasys/index.html>

- 27 referenced external assets/runtimes archived.
- Source and local page title, dimensions, route, and section geometry match.

- `inline-scripts.json` and `webflow-interaction-ids.json` preserve interaction configuration and hooks.

No masks, clipping effects, transitions, or product motion have been reauthored or approximated.
