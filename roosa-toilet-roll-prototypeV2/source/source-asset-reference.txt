Geometry: a SINGLE mesh named "ToiletPaper" — no separate core / wrapped
paper / loose sheet, no morph targets, no animations. Inspected in Three.js it
is a thin, open ~270° paper shell with a modelled flap and hollow, open ends —
built to be viewed in one static pose, not spun or shrunk.

This folder keeps ToiletPaper_HI.obj purely as a geometry reference. The
prototype does NOT load it at runtime (see README, "Why the roll is rebuilt").
What the prototype DOES use from this asset is its real 4K cherry-blossom quilt,
cropped from T_ToiletPaper_Normal.png / _BaseColor.png into model/quilt_*.webp.
