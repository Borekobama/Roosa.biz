# Bovist 1:1 reference capture

Source: <https://bovist.webflow.io/>

Local home: <http://127.0.0.1:3000/bovist/index.html>

The literal crawl preserved 57 valid routes: the home page, 14 collections, 15 vendors, 17 products, all-products, brands, cart, login/register/recovery/account pages, about, contact, policies, and style guide. Every valid route has an untouched `source.html` and an internally linked `index.html`.

The source homepage measures 7,035 px at 1,440 × 1,000. The locally served HTML, CSS, imagery, Webflow code, and Smootify hooks are captured intact. Smootify detects `127.0.0.1` as an unlicensed custom domain and replaces some hydrated runtime content, producing a 6,258 px local document and its own warning toast. That difference is generated by Smootify after load; it is not an interpreted layout or omitted source markup. The untouched source documents remain available for the later commerce-architecture implementation.

Files:

- `home-topology.json`: homepage geometry, navigation, scripts, and source routes.
- `manifest.json`: all page/asset capture results.
- `public/bovist/**/source.html`: untouched documents.
- `public/bovist/**/index.html`: locally linked documents.
- `docs/design-references/bovist/`: source/local visual evidence.

The 30 recorded page errors are false URLs produced by comma-separated variable-font axis syntax being interpreted as links by the generic crawler; they all return source 404s and do not represent missing site pages.
